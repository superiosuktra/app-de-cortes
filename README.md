# app-de-cortes

Aplicação React + Vite com backend Express para análise e edição de cortes virais.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Páginas legais públicas

Os documentos legais ficam versionados em arquivos estáticos:

- `/home/runner/work/app-de-cortes/app-de-cortes/public/privacy.html`
- `/home/runner/work/app-de-cortes/app-de-cortes/public/terms.html`

Após deploy, as URLs públicas para cadastro em plataformas (ex.: TikTok) são:

- `https://SEU_DOMINIO/privacy`
- `https://SEU_DOMINIO/terms`

Também é possível acessar os arquivos estáticos diretamente por:

- `https://SEU_DOMINIO/privacy.html`
- `https://SEU_DOMINIO/terms.html`
